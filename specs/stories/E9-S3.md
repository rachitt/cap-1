## Description

Closes gap G-03. A root plugin.json packages the banking substrate and must be distinct from the pre-existing .claude/.claude-plugin/plugin.json, which describes the Harness foundation. Reviewers check for both, so the root manifest must reference the banking agents, skills, commands and hooks specifically.

## Acceptance Criteria

**AC1.** A `plugin.json` exists at the repository root, parses as valid JSON, and declares a name, version and description identifying the banking substrate (mandatory deliverable, gap G-03).

| Feature | Category | Verifies |
|---|---|---|
| `F255` | integration | The root plugin.json exists, parses, and identifies the banking substrate |

**AC2.** The root `plugin.json` is a distinct file from `.claude/.claude-plugin/plugin.json`, with different content; both exist simultaneously (gap G-03).

| Feature | Category | Verifies |
|---|---|---|
| `F256` | integration | The root and Harness plugin manifests both exist and differ in content |

**AC3.** The root manifest enumerates the banking-specific agents, skills, commands and hooks added in E8-S2, and every path it references resolves to a file that exists.

| Feature | Category | Verifies |
|---|---|---|
| `F257` | integration | Every substrate path referenced by the root plugin manifest resolves to an existing file |

## Verification Steps

**`F255` — The root plugin.json exists, parses, and identifies the banking substrate** _(AC1, integration)_

1. Assert plugin.json exists at the repository root
1. Parse it with json.loads and assert it loads without error
1. Assert it declares name, version and description fields
1. Assert the description identifies the ClaudeForge banking substrate rather than the generic Harness

**`F256` — The root and Harness plugin manifests both exist and differ in content** _(AC2, integration)_

1. Assert both plugin.json and .claude/.claude-plugin/plugin.json exist
1. Compute a hash of each file's contents
1. Assert the two hashes differ
1. Assert the root manifest declares a different name from the Harness manifest

**`F257` — Every substrate path referenced by the root plugin manifest resolves to an existing file** _(AC3, integration)_

1. Parse plugin.json and collect every referenced agent, skill, command and hook path
1. Assert the manifest references at least 2 agents, 2 skills, 2 commands and 1 hook
1. Assert every referenced path exists on disk
1. Assert no referenced path points outside the repository
