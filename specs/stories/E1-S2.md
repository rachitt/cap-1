## Description

Configuration holds the values the application needs to run: the JWT signing key and lifetime, the database URL, and the default statement page size. Per DR-19 and DR-24 no transfer cap and no loan eligibility thresholds exist, so no such values appear here. Secrets are read from the environment and never committed. Values here are runtime implementation details, not business rules.

## Acceptance Criteria

**AC1.** `Settings` exposes `jwt_secret_key` sourced from the `JWT_SECRET_KEY` environment variable with no committed default value; instantiating Settings without that variable raises a validation error rather than falling back to a built-in key.

| Feature | Category | Verifies |
|---|---|---|
| `F006` | security | The JWT signing key is environment-sourced with no hard-coded fallback |

**AC2.** `Settings` exposes `jwt_expiry_minutes` and `database_url`, both overridable by environment variable; the token lifetime is a runtime setting, so tests assert issued tokens match the configured value rather than a fixed literal.

| Feature | Category | Verifies |
|---|---|---|
| `F007` | functional | JWT expiry and database URL are typed settings overridable from the environment |

**AC3.** `Settings` exposes a default statement page size used when a caller supplies none, supporting the DR-13 requirement that statements are always paginated; the value is configurable rather than hard-coded in the service layer.

| Feature | Category | Verifies |
|---|---|---|
| `F008` | functional | The default statement page size is a configurable setting, not a service-layer literal |

**AC4.** The Config layer contains no transfer cap, velocity limit, or loan eligibility threshold, per DR-19 and DR-24; a grep for `cap`, `limit`, `max_principal` and `income` across `backend/src/config/` returns no such setting.

| Feature | Category | Verifies |
|---|---|---|
| `F009` | integration | No invented transfer cap or loan eligibility threshold exists in configuration |

**AC5.** The `config` package imports only from `types`, `uv run mypy --strict src/config/` reports zero errors, and a `.env.example` documents every required variable with placeholder values only.

| Feature | Category | Verifies |
|---|---|---|
| `F010` | integration | Config layer imports no layer above Types and typechecks strictly |
| `F011` | security | A .env.example documents required variables and contains no real secret values |

## Verification Steps

**`F006` — The JWT signing key is environment-sourced with no hard-coded fallback** _(AC1, security)_

1. Run: grep -rniE 'secret[_-]?key\s*[:=]\s*["'\''][A-Za-z0-9]' backend/src/config/
1. Assert the command produces no output (no literal key assigned in source)
1. Unset JWT_SECRET_KEY and instantiate Settings inside pytest.raises for a validation error
1. Assert the error is raised and no default key is used

**`F007` — JWT expiry and database URL are typed settings overridable from the environment** _(AC2, functional)_

1. Instantiate Settings with JWT_SECRET_KEY set and assert jwt_expiry_minutes is a positive int
1. Set JWT_EXPIRY_MINUTES='15' and reload Settings
1. Assert settings.jwt_expiry_minutes == 15
1. Set DATABASE_URL to a temporary path, reload, and assert settings.database_url reflects it

**`F008` — The default statement page size is a configurable setting, not a service-layer literal** _(AC3, functional)_

1. Instantiate Settings and assert statement_page_size is a positive int
1. Override STATEMENT_PAGE_SIZE='5' in the environment and reload Settings
1. Assert settings.statement_page_size == 5
1. Run: grep -rnE 'page_size\s*=\s*[0-9]+' backend/src/service/ and assert no hard-coded default is found

**`F009` — No invented transfer cap or loan eligibility threshold exists in configuration** _(AC4, integration)_

1. Run: grep -rniE 'daily_cap|transfer_cap|velocity|max_principal|min_principal|income_ratio|max_tenure' backend/src/config/
1. Assert the command exits with status 1 (no matches)
1. Introspect the Settings model field names and assert none contains 'cap' or 'eligib'

**`F010` — Config layer imports no layer above Types and typechecks strictly** _(AC5, integration)_

1. Run: grep -rnE 'from (backend\.)?src\.(repository|service|api)' backend/src/config/
1. Assert the command exits with status 1
1. Run: cd backend && uv run mypy --strict src/config/ and assert exit code 0

**`F011` — A .env.example documents required variables and contains no real secret values** _(AC5, security)_

1. Assert backend/.env.example exists and contains JWT_SECRET_KEY and DATABASE_URL
1. Assert .env is listed in .gitignore
1. Assert no value in .env.example matches a high-entropy secret pattern
