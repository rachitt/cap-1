## Description

The second of four mandated domain policy files. Pure and dependency-free, it validates document type and format and returns a deterministic verdict per DR-08 so the rejection path stays testable. Per DR-07 the brief specifies no age, date-of-birth or other registration eligibility criteria, so none are imposed.

## Acceptance Criteria

**AC1.** `verify(document)` returns `VERIFIED` for a well-formed document (recognised type plus a document number matching the declared format), and returns `REJECTED` with a `stub_reason` for the reserved synthetic document number `X0000000` (assumption A-02).

| Feature | Category | Verifies |
|---|---|---|
| `F032` | functional | A well-formed KYC document deterministically returns a VERIFIED verdict |
| `F033` | functional | The reserved synthetic document number always returns REJECTED with a non-empty stub_reason |

**AC2.** An unrecognised `document_type` or a `document_number` failing the format rule raises a validation error rather than returning a verdict, so malformed submissions surface as 422 rather than a silent rejection.

| Feature | Category | Verifies |
|---|---|---|
| `F034` | functional | Unrecognised document types and malformed document numbers raise a validation error |

**AC3.** The policy imposes no age, date-of-birth or other registration eligibility criterion (DR-07): a well-formed document verifies regardless of the applicant's date of birth, and the module exposes no age-checking function.

| Feature | Category | Verifies |
|---|---|---|
| `F035` | functional | KYC verification does not gate on applicant age or date of birth |
| `F036` | integration | No age or eligibility threshold function exists in the KYC policy module |

**AC4.** The module is pure: it imports only `datetime`, `typing` and `backend/src/types`, performs no I/O, and `uv run mypy --strict src/domain/kyc_policy.py` reports zero errors.

| Feature | Category | Verifies |
|---|---|---|
| `F037` | integration | The KYC policy module is dependency-free and performs no I/O |

## Verification Steps

**`F032` — A well-formed KYC document deterministically returns a VERIFIED verdict** _(AC1, functional)_

1. Call verify with document_type='PASSPORT' and document_number='P1234567'
1. Assert the returned verdict status is KycStatus.VERIFIED
1. Call verify twice more with identical input and assert the verdict is VERIFIED every time (determinism)

**`F033` — The reserved synthetic document number always returns REJECTED with a non-empty stub_reason** _(AC1, functional)_

1. Call verify with document_type='PASSPORT' and document_number='X0000000'
1. Assert the verdict status is KycStatus.REJECTED
1. Assert the verdict stub_reason is a non-empty string
1. Repeat the call three times and assert the result is REJECTED each time

**`F034` — Unrecognised document types and malformed document numbers raise a validation error** _(AC2, functional)_

1. Call verify with document_type='LIBRARY_CARD' inside pytest.raises and assert a validation error is raised
1. Call verify with document_type='PASSPORT' and document_number='!!' and assert a validation error is raised
1. Assert neither call returns a KycVerdict object

**`F035` — KYC verification does not gate on applicant age or date of birth** _(AC3, functional)_

1. Call verify with a well-formed document for an applicant whose date_of_birth is 16 years ago
1. Assert the verdict status is KycStatus.VERIFIED
1. Repeat with a date_of_birth 60 years ago and assert the verdict is also VERIFIED
1. Assert the verdict does not differ based on date_of_birth

**`F036` — No age or eligibility threshold function exists in the KYC policy module** _(AC3, integration)_

1. Run: grep -niE 'age|18|eligib|minor|adult' backend/src/domain/kyc_policy.py
1. Assert the command exits with status 1 (no matches)

**`F037` — The KYC policy module is dependency-free and performs no I/O** _(AC4, integration)_

1. Run: grep -nE '^(from|import) ' backend/src/domain/kyc_policy.py
1. Assert every import references only datetime, typing, dataclasses, enum or src.types
1. Run: grep -nE 'open\(|requests\.|httpx\.|session|engine' backend/src/domain/kyc_policy.py and assert no matches
1. Run: cd backend && uv run mypy --strict src/domain/kyc_policy.py and assert exit code 0
