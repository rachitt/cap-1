## Description

Closes gap G-02. Configuration alone is explicitly insufficient: the evaluator must actually invoke Playwright MCP and that invocation must leave evidence. The E2E suite covers each AC journey end to end against the seeded system, captures snapshots at all three breakpoints, and runs the axe checks introduced in E7-S3.

## Verification Steps

**`F245` — The root .mcp.json declares a Playwright MCP server and parses as valid JSON** _(AC1, integration)_

1. Assert .mcp.json exists at the repository root
1. Parse it with json.loads and assert it loads without error
1. Assert it contains an mcpServers entry naming a Playwright server
1. Assert the entry declares a runnable command

**`F246` — An evaluator run produces a committed artefact evidencing Playwright MCP invocation** _(AC2, integration)_

1. Run the evaluator against the running application
1. Assert an artefact is written under specs/reviews/ for that run
1. Assert the artefact records the Playwright MCP driven UI verification steps and their pass or fail outcome
1. Assert the artefact references at least one screen verified through MCP rather than through direct HTTP calls

**`F247` — The E2E suite covers every acceptance criterion journey and passes** _(AC3, integration)_

1. Run the Playwright suite against the seeded running system
1. Assert the process exit code is 0
1. Assert at least one spec exists referencing each of AC-01 through AC-10 by identifier
1. Assert the onboarding, transfer, loan application and admin review journeys each have a passing spec

**`F248` — An end-to-end transfer journey asserts money conservation in the browser** _(AC3, integration)_

1. Log in as a seeded funded customer and record the displayed balances of both accounts
1. Complete a transfer through the UI
1. Assert the source balance decreased and the destination increased by exactly the transferred amount
1. Assert the sum of the two displayed balances is unchanged

**`F249` — Snapshots are committed for all three breakpoints and are stable across runs** _(AC4, ui)_

1. Run the Playwright suite with snapshot capture enabled
1. Assert a committed snapshot directory exists containing images for the 375px, 768px and 1440px viewports
1. Re-run the suite against unchanged UI
1. Assert no snapshot comparison failure is reported
