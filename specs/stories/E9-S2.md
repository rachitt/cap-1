## Description

Brief section 7.1 requires programmatic Agent SDK usage under scripts/, and it is the item most often missed because it is satisfied by neither a slash command nor an agent definition. This must be a real executable Python script that imports the Claude Agent SDK and drives an agent programmatically against this repository.

## Acceptance Criteria

**AC1.** A Python script under `scripts/` imports the Claude Agent SDK and invokes it programmatically; a grep confirms a genuine SDK import rather than a subprocess shell-out to the CLI (M-22).

| Feature | Category | Verifies |
|---|---|---|
| `F250` | integration | A script under scripts/ imports and invokes the Claude Agent SDK programmatically |
| `F251` | integration | The SDK script is executable and exits cleanly in a dry-run mode |

## Verification Steps

**`F250` — A script under scripts/ imports and invokes the Claude Agent SDK programmatically** _(AC1, integration)_

1. List Python files under scripts/ and assert at least one exists
1. Run: grep -rnE 'claude_agent_sdk|claude_code_sdk' scripts/ and assert at least one import match
1. Assert the script calls an SDK entry point such as a query or client invocation
1. Assert the file is not merely a slash command definition or an agent markdown file

**`F251` — The SDK script is executable and exits cleanly in a dry-run mode** _(AC1, integration)_

1. Run the script with a dry-run or help flag
1. Assert the process exits with status 0
1. Assert it prints a usage or plan summary rather than raising an import error

**`F252` — The SDK script performs a real repository task and writes an output artefact** _(AC2, functional)_

1. Run the script against the repository
1. Assert it exits with status 0
1. Assert it writes an output artefact to a documented path
1. Assert the artefact content reflects actual repository state rather than static placeholder text

**`F253` — The SDK script contains no committed credential** _(AC3, security)_

1. Run: grep -nE 'sk-ant-[A-Za-z0-9]' scripts/ and assert no match
1. Assert the script reads its key from an environment variable
1. Run the detect-secrets hook against scripts/ and assert it reports no findings

**`F254` — The Agent SDK is a declared dependency rather than an ambient install** _(AC4, integration)_

1. Locate the dependency manifest covering scripts/
1. Assert the Claude Agent SDK package is listed as a dependency
1. Assert a lockfile entry exists for it
1. Install from the manifest in a clean environment and assert the script imports successfully
