## Description

NFR-01 is the highest-severity invariant in the system: money must never touch a float. This story delivers `backend/src/domain/money.py` as a dependency-free Layer-1 policy module providing Decimal construction, 2-decimal-place validation, ROUND_HALF_UP rounding, sign guards, and string parse/format helpers. It is the first of the four mandated domain policy files.

## Acceptance Criteria

**AC1.** `parse_money(value: str) -> Decimal` accepts `'1234.56'` and returns `Decimal('1234.56')`, and raises a `MoneyPrecisionError` for any input carrying more than 2 decimal places such as `'10.005'`.

| Feature | Category | Verifies |
|---|---|---|
| `F012` | functional | parse_money returns an exact Decimal for well-formed 2dp input |
| `F013` | functional | parse_money rejects input with more than two decimal places instead of silently rounding |

**AC2.** `quantize_money(value: Decimal) -> Decimal` applies `ROUND_HALF_UP` to 2 decimal places, so `Decimal('2.345')` becomes `Decimal('2.35')` and `Decimal('2.344')` becomes `Decimal('2.34')`.

| Feature | Category | Verifies |
|---|---|---|
| `F014` | functional | quantize_money rounds half away from zero to two decimal places |

**AC3.** `require_positive(value: Decimal)` raises for `Decimal('0.00')` and negative values, and `require_non_negative(value: Decimal)` accepts `Decimal('0.00')` but raises for negatives.

| Feature | Category | Verifies |
|---|---|---|
| `F015` | functional | Positive and non-negative money guards distinguish zero correctly |

**AC4.** `format_money(value: Decimal) -> str` always emits exactly two decimal places, so `Decimal('5')` renders as `'5.00'`, and the value is serialised as a JSON string rather than a JSON number.

| Feature | Category | Verifies |
|---|---|---|
| `F016` | functional | format_money renders a fixed two-decimal string for whole and fractional amounts |

**AC5.** The module contains no `float` usage anywhere: a grep for `float(`, `: float` and `%f` across `backend/src/domain/money.py` returns zero matches, and the module imports nothing outside `decimal` and `backend/src/types`.

| Feature | Category | Verifies |
|---|---|---|
| `F017` | security | The money policy module contains no float construction or float type annotation |

## Verification Steps

**`F012` — parse_money returns an exact Decimal for well-formed 2dp input** _(AC1, functional)_

1. Call parse_money('1234.56')
1. Assert the result equals Decimal('1234.56') exactly
1. Assert the result type is Decimal and not float

**`F013` — parse_money rejects input with more than two decimal places instead of silently rounding** _(AC1, functional)_

1. Call parse_money('10.005') inside a pytest.raises(MoneyPrecisionError) block
1. Assert the exception is raised
1. Call parse_money('10.001') and assert MoneyPrecisionError is raised
1. Assert no rounded value such as Decimal('10.00') is ever returned for these inputs

**`F014` — quantize_money rounds half away from zero to two decimal places** _(AC2, functional)_

1. Assert quantize_money(Decimal('2.345')) == Decimal('2.35')
1. Assert quantize_money(Decimal('2.344')) == Decimal('2.34')
1. Assert quantize_money(Decimal('2.355')) == Decimal('2.36')
1. Assert the returned exponent is -2 for every case

**`F015` — Positive and non-negative money guards distinguish zero correctly** _(AC3, functional)_

1. Assert require_positive(Decimal('0.01')) does not raise
1. Assert require_positive(Decimal('0.00')) raises a DomainError subclass
1. Assert require_positive(Decimal('-1.00')) raises
1. Assert require_non_negative(Decimal('0.00')) does not raise while require_non_negative(Decimal('-0.01')) raises

**`F016` — format_money renders a fixed two-decimal string for whole and fractional amounts** _(AC4, functional)_

1. Assert format_money(Decimal('5')) == '5.00'
1. Assert format_money(Decimal('1234.5')) == '1234.50'
1. Assert format_money(Decimal('0')) == '0.00'

**`F017` — The money policy module contains no float construction or float type annotation** _(AC5, security)_

1. Run: grep -nE 'float\(|:\s*float|%f' backend/src/domain/money.py
1. Assert the command exits with status 1 (no matches)
1. Run: grep -nE '^(from|import) ' backend/src/domain/money.py
1. Assert every import line references only decimal, typing, or src.types
