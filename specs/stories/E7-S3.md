## Description

The cross-cutting quality pass over every screen. Brief section 7.2 requires at least one explicitly responsive layout; the BRD targets mobile-first customer journeys at 375px and 768px with the admin tables at 1440px. Accessibility targets WCAG 2.1 AA with automated axe checks, keyboard operability of the transfer and loan review flows, and visible focus indicators.

## Acceptance Criteria

**AC1.** Every customer screen renders without horizontal overflow at 375px and 768px, and the admin queue and audit tables remain usable at 1440px (brief section 7.2).

| Feature | Category | Verifies |
|---|---|---|
| `F215` | ui | Customer screens render without horizontal overflow at mobile and tablet widths |
| `F216` | ui | Admin tabular screens remain usable at the desktop breakpoint |

**AC2.** An automated axe scan reports zero violations of serious or critical impact on every screen at the mobile and desktop breakpoints.

| Feature | Category | Verifies |
|---|---|---|
| `F217` | ui | Axe reports zero serious or critical violations across all screens |

**AC3.** The transfer flow and the loan review flow are fully operable by keyboard alone, from field entry through confirmation, with a visible focus indicator on every interactive element.

| Feature | Category | Verifies |
|---|---|---|
| `F218` | ui | The transfer flow can be completed end to end using only the keyboard |
| `F219` | ui | The loan review flow including the reason field is keyboard operable |

**AC4.** Every screen uses semantic landmarks and a single `h1`, and all text including every money value meets AA contrast of at least 4.5:1.

| Feature | Category | Verifies |
|---|---|---|
| `F220` | ui | Each screen exposes semantic landmarks and exactly one h1 |
| `F221` | ui | All rendered money values meet AA contrast against their background |

## Verification Steps

**`F215` — Customer screens render without horizontal overflow at mobile and tablet widths** _(AC1, ui)_

1. Load each customer screen in Playwright at a 375px viewport
1. Assert document.scrollWidth is not greater than the 375px viewport width on each
1. Repeat at a 768px viewport and assert no horizontal overflow on each screen

**`F216` — Admin tabular screens remain usable at the desktop breakpoint** _(AC1, ui)_

1. Load the admin loan queue and audit log at a 1440px viewport
1. Assert all table column headers are visible without horizontal scrolling
1. Assert row action controls are reachable and not clipped

**`F217` — Axe reports zero serious or critical violations across all screens** _(AC2, ui)_

1. Run an axe scan against each of the eleven screens at a 375px viewport
1. Assert the count of violations with impact 'serious' or 'critical' is 0 for each
1. Repeat the scan at a 1440px viewport and assert the same
1. Write the axe results to a committed artefact for evidence

**`F218` — The transfer flow can be completed end to end using only the keyboard** _(AC3, ui)_

1. Load the Transfer screen in Playwright and navigate using Tab and Enter only
1. Complete destination entry, amount entry and confirmation without using the mouse
1. Assert the success state is reached
1. Assert every focused element shows a visible focus indicator distinguishable from its unfocused state

**`F219` — The loan review flow including the reason field is keyboard operable** _(AC3, ui)_

1. Load the admin LoanQueue and navigate to a loan's approve action using the keyboard only
1. Enter a reason and submit using the keyboard only
1. Assert the decision is submitted successfully
1. Assert focus is moved to the resulting status message

**`F220` — Each screen exposes semantic landmarks and exactly one h1** _(AC4, ui)_

1. Load each screen and query for main, nav and header landmark roles
1. Assert a main landmark is present on every screen
1. Assert exactly one h1 element exists per screen

**`F221` — All rendered money values meet AA contrast against their background** _(AC4, ui)_

1. Load the Dashboard, AccountDetail and Transfer screens
1. Compute the computed-style contrast ratio for each rendered money element against its background
1. Assert every ratio is at least 4.5:1
