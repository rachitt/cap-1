    AC-06 · optional convenience

    Saved payees

    A saved payee is an address-book entry. It fills the destination field for you. It is never a condition of sending money.

      GET /api/v1/beneficiaries DELETE /api/v1/beneficiaries/{beneficiary_id} → 204

      No saved payees

      Saving a payee stores a nickname against an account number so you do not have to type it again. Sending money works either way.

      Add a payee

      Must resolve to an existing Horizon account, or the API returns 404.

      POST /api/v1/beneficiaries 409 DUPLICATE_BENEFICIARY

      Removal is a soft delete

      Removing a payee sets deleted_at and hides it from this list. Historical transfers and audit entries that referenced it are untouched.
